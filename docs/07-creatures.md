## Anatomy Reference

Use `mirror:"x"` for bilateral symmetry (wings, legs, eyes).
Use `radialRepeat` for radial symmetry (spider legs, octopus tentacles).
Use `repeat` with `step` for segmented bodies (snake, centipede).
